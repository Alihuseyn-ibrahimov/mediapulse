Məxfilik Siyasəti

Son yenilənmə: 2026-07-11

MediaPulse (mediapulse.az) — media monitorinq platformasıdır. Bu sənəd hansı məlumatları topladığımızı, necə istifadə etdiyimizi və necə qoruduğumuzu izah edir.

1. Topladığımız məlumatlar

  • Hesab məlumatları: ad, e-poçt, təşkilat adı (qeydiyyat zamanı istifadəçi tərəfindən verilir).
  • İzləmə açar sözləri: müştərinin izləmək istədiyi brend/açar sözlər.
  • Ictimai media məzmunu: xəbər saytları, sosial media (o cümlədən Facebook səhifələrinin ictimai paylaşımları) və TV kanallarından açar sözlərə uyğun ictimai şəkildə əlçatan məzmun.

2. Facebook məlumatlarının istifadəsi

MediaPulse, Facebook Graph API vasitəsilə yalnız ictimai (public) Səhifə paylaşımlarını oxuyur — müştərilərimizin əvvəlcədən müəyyən etdiyi açar sözlərə uyğun media səhifələrini media-monitorinq məqsədilə izləmək üçün. Biz:

  • şəxsi istifadəçi profillərinə, dostluq siyahılarına və ya şəxsi (qeyri-ictimai) paylaşımlara müraciət etmirik;
  • əldə edilən məzmunu yalnız açar-söz uyğunluğu axtarışı və müştəri dashboard-unda göstərmək üçün istifadə edirik;
  • heç bir Facebook məlumatını üçüncü tərəflərə satmır və ya reklam məqsədilə istifadə etmirik;
  • məlumatları yalnız xidmətin fəaliyyəti üçün lazım olan müddətdə saxlayırıq.

3. Məlumatların saxlanması və təhlükəsizliyi

Bütün məlumatlar şifrələnmiş serverdə saxlanılır, girişə yalnız səlahiyyətli sistem hesabları icazəlidir. Server SSL/TLS ilə qorunur, müntəzəm ehtiyat nüsxələri şifrələnmiş şəkildə saxlanılır.

4. Məlumatların paylaşılması

Toplanan məlumatlar yalnız müvafiq müştəri təşkilatının öz dashboard-unda göstərilir. Başqa təşkilatlarla və ya üçüncü tərəflərlə paylaşılmır.

5. Sizin hüquqlarınız

Hesabınızla bağlı məlumatların silinməsini və ya dəyişdirilməsini istənilən vaxt aşağıdakı əlaqə vasitəsilə tələb edə bilərsiniz.
